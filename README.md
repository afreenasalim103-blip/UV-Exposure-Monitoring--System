# 🌞 UV Exposure Monitoring and Sunscreen Recommendation System

## 📌 Overview
The UV Exposure Monitoring and Sunscreen Recommendation System is a mobile application developed to help users protect their skin from harmful ultraviolet (UV) radiation. The application monitors the real-time UV Index based on the user's location, predicts the user's skin type using image processing and machine learning, and recommends the appropriate SPF sunscreen for better skin protection.

## ✨ Features
- Real-time UV Index monitoring
- Skin type detection using image processing
- Personalized SPF sunscreen recommendation
- User authentication
- Sun exposure tracking
- Sunscreen product recommendations
- Admin dashboard for managing users and products

## 🛠️ Technologies Used
- Flutter (Frontend)
- Python (Machine Learning)
- Supabase (Backend & Database)
- PostgreSQL
- OpenWeather API
- MobileNetV2 (Transfer Learning)
- CNN (Convolutional Neural Network)

## 🚀 How to Run
1. Clone the repository.
2. Install Flutter and Python dependencies.
3. Configure Supabase and OpenWeather API credentials.
4. Run the Flutter application:
```bash
flutter pub get
flutter run
```
